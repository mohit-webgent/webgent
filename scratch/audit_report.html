🔒 3. Security, Hardening & Vulnerability Findings
1. Hardcoded Default Fallback AUTH_SECRET in Environment Schema HIGH SEVERITY
File: src/lib/env.ts:16
AUTH_SECRET is configured with a default fallback string: "a_very_secret_32_character_long_auth_secret_key_webgent". If the production environment variable is omitted or improperly configured during deployment, NextAuth silently defaults to this known public string. An attacker possessing this repository code could forge administrative JWT tokens and gain full admin access.
Remediation: Remove default string in production: AUTH_SECRET: z.string().min(32, "AUTH_SECRET must be at least 32 characters in production").
2. Overly Permissive Remote Image Optimization Pattern (SSRF Risk) HIGH SEVERITY
File: next.config.mjs:9
The remote pattern { protocol: "https", hostname: "**" } permits Next.js Image Optimization to request, proxy, and optimize images from any arbitrary host on the internet. Malicious actors could supply internal intranet IPs or trigger denial-of-service through continuous optimization requests for massive external payloads.
Remediation: Restrict remotePatterns to explicit trusted image domains (e.g. Cloudflare R2 bucket domain, images.unsplash.com).
3. Missing Standard HTTP Security Headers HIGH SEVERITY
Files: next.config.mjs and src/middleware.ts
HTTP security headers (X-Frame-Options, X-Content-Type-Options, Referrer-Policy, Permissions-Policy, and Strict-Transport-Security) are not defined in the configuration or middleware. The application is vulnerable to UI clickjacking and MIME-type confusion attacks in older user agents.
Remediation: Define security headers in next.config.mjs under the headers() configuration function.
4. Schema Migration Drift vs. Production Baseline MEDIUM SEVERITY
Directory: prisma/migrations/
Migration files in prisma/migrations only cover up to Phase 5. Subsequent features (testimonials, newsletter, analytics, site settings, chat) were deployed into the local database using prisma db push. Running prisma migrate deploy in a fresh CI/CD production deployment would skip tables added in Phases 6–15.
Remediation: Execute npx prisma migrate dev --name sync_all_phases to produce a unified, reproducible migration history for production CI/CD pipelines.
5. In-Memory Rate Limiter Lacks Garbage Collection & Multi-Instance Sharing MEDIUM SEVERITY
File: src/lib/rate-limit.ts:6
rateLimitStore = new Map() does not prune stale keys, creating an unbounded memory accumulation vector on long-running servers. Furthermore, in serverless environments (Vercel/Lambda) or clustered containers, in-memory state is not shared across replicas.
Remediation: Implement an active TTL purge interval (e.g., every 10 minutes) for in-memory use, or connect to Upstash Redis for distributed deployments.
6. TURNSTILE_SECRET_KEY Omitted from Central Env Schema LOW SEVERITY
Files: src/lib/env.ts and src/lib/turnstile.ts:15
Turnstile verification directly inspects process.env.TURNSTILE_SECRET_KEY rather than the centralized validated env object in src/lib/env.ts.
Remediation: Add TURNSTILE_SECRET_KEY: z.string().optional() to envSchema and export with the global environment configuration.

⚙️ 4. Subsystem Architectural Review
Auth & RBAC Control Robust
NextAuth v5 (beta) with custom credentials provider. Double verification: Edge Middleware protects /admin/* and /api/admin/*, while server-side verifyAdminApiAccess() ensures route handlers independently enforce ACTIVE status and ADMIN/EDITOR roles.
Cloudflare R2 Media Engine Secure
S3-compatible storage pipeline featuring binary magic-number validation (JPEG, PNG, WEBP), strict 5MB size limit, folder isolation (projects, blog, testimonials), and path traversal protection on deletion.
AI Concierge (Claude 3.5) Hardened
Custom system prompt with firm guardrails against pricing hallucination, warranty fabrication, and out-of-scope topics. Active regex-based prompt abuse and jailbreak detection, paired with a deterministic offline fallback engine.
